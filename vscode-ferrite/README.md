# Ferrite E2E VS Code Extension

Provides syntax highlighting, bracket/quote auto-closing, code folding, and snippets for `.ferrite` E2E test files.

## Local Installation (Windows)

Run from the repository root:

```powershell
.\scripts\install-vscode-ext.ps1
```

Then reload VS Code (`Ctrl+Shift+P` -> `Developer: Reload Window`).
